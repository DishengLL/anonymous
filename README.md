# Anonymous Repository

This anonymous repository is provided to demonstrate the performance comparison between the proposed method and baseline approaches.

## Demo Results

- **single_image_demo.pdf**  
  Demonstrates the inference pipeline under the single-image input setting on the RefCOCO+ dataset, and provides qualitative comparisons between our method and SpatialReasoner on representative examples.

- **multi_image_demo.pdf**  
  Demonstrates the inference pipeline under the multi-image input setting on the RefCOCO+ dataset, and provides qualitative comparisons between our method and SpatialReasoner on representative examples.
